Bacterial Coexistence

All code and data included in this repository correspond to the data utilized and analyses performed for the manuscript titled: Environmental complexity shapes the maintenance of bacterial diversity through context-dependent interactions among niche axes.

This research involved two independent experiments that are referred to throughout the code by one of three identifiers as follows: 
Experiment 1 / PMXC7 / CR.M9
Experiment 2 / PMXC6 / CR.R2A
